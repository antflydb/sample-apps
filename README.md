# Antfly sample apps

Small, complete apps built on [Antfly](https://github.com/antflydb/antfly).
Each one runs on its own; copy the directory and change what you need.

| App | What it shows |
| --- | --- |
| [simple-file-search](simple-file-search) | Search photos, recordings, and PDFs in S3 buckets and Google Drive folders with words, an image, or both. Go and React, with EmbeddingGemma 2 for images and text and Whisper for audio. |
